# mentorias-bda-uav
Módulo de persistencia y base de datos relacional en Microsoft SQL Server (Transact-SQL) para el Sistema de Gestión y Agendamiento de Mentorías de la Universidad Anáhuac Veracruz campus Córdoba-Orizaba.
